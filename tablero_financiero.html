El Excel actualizado del mes. Alimenta todo el seguimiento.

Podés cargar varias empresas: el tablero muestra cada una y el consolidado. Los archivos se leen en esta computadora: no se suben a ningún servidor.

1Actualizá la planilla

Cargá en el Excel los datos del mes y guardalo (Excel recalcula al guardar; el tablero lee los valores guardados).

2Cargá los dos archivos

Plan inicio (1/7) para la solapa Plan y plan actual para el seguimiento. Si falta el actual, el seguimiento usa el de inicio.

3Presentalo

Elegí empresa o consolidado y moneda. Con "Imprimir / PDF" sale una versión para repartir en la reunión.
